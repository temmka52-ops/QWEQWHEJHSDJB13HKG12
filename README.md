# Сайт для копирования текста

Простой адаптивный сайт: текст можно скопировать одной кнопкой на компьютере или телефоне.

## Публикация на Vercel

1. Распакуйте архив.
2. Откройте https://vercel.com/new
3. Загрузите папку в GitHub и импортируйте репозиторий в Vercel или выполните в папке команду `vercel`.
4. Framework Preset: **Other**.
5. Build Command и Output Directory оставьте пустыми.
6. Нажмите **Deploy**.

После публикации Vercel выдаст HTTPS-ссылку, которая будет открываться на любом устройстве.
